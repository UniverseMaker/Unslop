# unslop: 업무 문서 윤문

## 실행기

이 스킬은 코드를 함께 담고 있다. 설치 없이 아래 실행기로 부른다.

```
python "${CLAUDE_SKILL_DIR}/scripts/run_unslop.py" <명령> ...
```

- Claude Code 는 `${CLAUDE_SKILL_DIR}` 를 이 스킬 폴더 경로로 바꿔 준다.
- 바뀌지 않은 환경(Claude 앱 등)에서는 이 SKILL.md 가 있는 폴더를 찾아 그 경로를 쓴다.
  ```
  find / -path "*unslop/scripts/run_unslop.py" 2>/dev/null | head -1
  ```
- PPTX·DOCX 에는 python-pptx·python-docx 가 필요하다. 없으면 `pip install python-pptx python-docx` 를 실행한다.

아래에서 `UNSLOP` 는 이 실행기를 뜻한다.

## 문서 종류(레지스터)

| 문서 | `--register` | 핵심 규칙 |
|---|---|---|
| 연구·기술보고서 본문 | `report` | 「~다」체 통일, 번역투·공허한 수식어·되풀이 요약 정리, 절 제목은 명사구 |
| 발표·연구노트 슬라이드 | `slide` | 모든 칸 개조식, 「대상 + 수치 + 업무 용어」, 발화 인용 금지, 원문보다 짧게 |
| 공문·내부 보고서(□○-·) | `brief` | 「~함/~임」·명사 종결, 계층 기호 순서 |

- 지정하지 않으면 pptx 는 `slide`, □○ 기호가 많으면 `brief`, 나머지는 `report` 다.
- 규칙 전체(코드·예시)는 `references/RULES.md` 에 있다.

## 절차

1. **검사**: `UNSLOP lint <파일>`
   - 오류·경고 수와 대표 위반을 사용자에게 보여 준다.

2. **요청 만들기**: `UNSLOP run <파일> --provider none [--register ...] [--keep "<바꾸면 안 되는 문구>"]`
   - 모델 출력 원문, 법령·규정 인용처럼 그대로 둬야 하는 줄은 `--keep` 으로 뺀다.
   - 이 단계에서 화살표·「N번 넘게」·띄어 쓴 조사·줄 끝 마침표는 자동으로 고쳐진다.
   - 출력에 나온 작업 폴더를 기억한다. 그 안의 파일:
     - `02_system_prompt.md`: 문서 종류별 규칙과 출력 형식
     - `02_user_prompt.md`: 윤문 대상 줄과 검사기 지적 사항

3. **윤문**: 두 파일을 읽고 같은 「[번호|종류] 본문」 형식으로 `<작업 폴더>/final.txt` 를 쓴다.
   - `02_system_prompt.md` 가 유일한 기준이다.
   - 번호·종류·줄 수·순서를 그대로 두고, 고칠 것이 없는 줄도 그대로 적는다.
   - ⟦ ⟧ 안(수치·버전·경로·영문 용어)은 바꾸지 않는다.
   - 지적된 줄은 반드시 고친다. 슬라이드는 제목·부제를 모두 다시 본다.
   - Claude Code 에 `unslop-rewriter` 에이전트가 있으면 작업 폴더 경로를 넘겨 맡겨도 된다.

4. **반영**: `UNSLOP apply <작업 폴더> <작업 폴더>/final.txt [-o <출력 파일>] [--source <생성 스크립트>]`
   - 게이트를 통과한 줄만 반영한다.
   - 막힌 줄은 `<작업 폴더>/report.md` 의 「원문 유지」에 사유가 있다. 그 줄만 고쳐 다시 apply 한다(최대 2회).
   - PPT 를 스크립트로 만든다면 `--source` 로 스크립트에 반영하고 스크립트를 다시 실행한다.

5. **보고**: `report.md` 의 표를 그대로 전하고, 결과 파일을 사용자에게 건넨다.
   - 오류·경고·등급 전후
   - 바뀐 단위 수
   - 원문 유지 줄
   - 바뀐 예 5개

## 슬라이드 문장 기준 (사용자 검토에서 확정)

| 고치기 전 | 고친 뒤 |
|---|---|
| 이번 달 한눈에 | 월간 요약 |
| 선행연구 190편을 받아서 열고 본문을 읽었다 | 선행연구 190편 조사 및 연구 완료 |
| 산불 데이터의 42%가 같은 틀 문장 | 산불 데이터 중복 건수 42% 이상 발견 |
| 숫자만 다른 줄은 같은 틀로 간주, 100번 넘게 나온 줄 집계 | 100회 이상 중복데이터 집계 |
| 실패 → 원인 실측 → 재설계 | 실패 > 원인 실측 > 재설계 |
| 사용자 지시: 「…계획부터 다시 짜라」 | 선행연구 조사 및 재계획 지시 |

## 지킬 것

- 원본 파일을 덮어쓰지 않는다. 기본 출력은 `<이름>.unslop.<확장자>` 다.
- 게이트를 우회하지 않는다. 막힌 줄을 손으로 끼워 넣지 않는다.
- 실패·하락·결함을 부드럽게 바꾸지 않는다. 원문에 없는 성과나 수식어를 넣지 않는다.

## API 로 돌릴 때 (선택)

```
UNSLOP run <파일> --provider anthropic     # Anthropic API, claude-opus-5-5
UNSLOP run <파일> --provider claude-cli    # 로그인된 Claude Code 헤드리스 실행
```
